Botão sobre outros aplicativos

No navegador a captura usa a API oficial do sistema (getDisplayMedia): você escolhe o que será capturado e autoriza a cada sessão. Uma página web não pode desenhar sobre outros apps nem capturar a tela do sistema livremente.

No app Android (camada nativa Kotlin incluída em docs/android) o botão flutuante vive numa sobreposição SYSTEM_ALERT_WINDOW mantida por um serviço em primeiro plano, e a captura acontece via MediaProjection. O app detecta essa ponte automaticamente.

Ponte nativa: não detectada (executando como PWA).
